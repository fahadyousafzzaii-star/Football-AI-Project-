# Football Player Performance Prediction with AI
## Summary
This is my final AI project for the Building AI course. The idea is to build an AI model that predicts football player performance and injury risk using GPS tracking, training load, match minutes and past injuries. The model will give a daily risk score Low/Medium/High to help coaches make better decisions and avoid losing important matches.
## How it works
The project will use supervised learning. We will collect data like distance run, sprint speed, heart rate, and injury history. Then we will train a Random Forest model to predict injury risk and performance drop. If model predicts high risk, coach can rest the player.
## Data needed
- GPS data: distance, sprints
- Match stats: minutes, passes, goals
- Fitness: heart rate, sleep
- Past injury records
## Future and Ethics
Player health data is private and must be protected. Data should be from all players to avoid bias. In future, I will make a simple mobile dashboard for coaches.
